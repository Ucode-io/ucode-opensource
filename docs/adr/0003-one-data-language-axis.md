# 3. Язык данных — одна ось на всё приложение

Дата: 2026-08-18
Статус: принято

## Контекст

В ucode два независимых языка, и путать их дорого (CONTEXT, [[Locale]]
и [[Data Language]]):

- **локаль интерфейса** — ru/en/uz, выбирает пользователь для себя;
- **язык данных** — набор языков ПРОЕКТА (в живом проекте это `en`
  и `cyr`), на них размечены подписи полей, варианты выбора, имена view,
  имена пунктов меню и значения мультиязычных полей.

Ключи в данных выглядят одинаково — `label_<код>`, `name_<код>`,
суффикс `_<код>` у слага, — и код в них ВСЕГДА из набора проекта.

Старая админка при загрузке насильно переключала i18n на первый язык
проекта. От этого `label_${i18n.language}` у неё случайно работал,
а интерфейс уезжал в язык данных: русский админ видел узбекские кнопки.

Новый фронт эту связку разорвал — и в трёх местах остался читать
данные по локали интерфейса:

- сайдбар (`toMenuNode(dto, i18n.language)`) — у проекта с языками
  `en`+`cyr` ключа `label_ru` нет, и пункты показывались базовой
  подписью из колонки;
- карточка записи держала свой выбор языка данных в `useState`;
- таблица языковые колонки не сводила вовсе.

## Решение

Язык данных — **одно значение на всё приложение**. Живёт в `ui-store`
(`dataLanguage`), читается через `useDataLanguages().current`, там же
проверяется по набору языков проекта: язык, убранный из настроек,
не должен показывать пустые подписи вечно.

Переключатель — общий компонент `LanguageTabs`, стоит в двух местах:
над таблицей и в карточке. Оба меняют одно и то же.

Локаль интерфейса не меняется от этого никогда.

## Последствия

Переключение языка данных меняет экран целиком: подписи колонок,
варианты выбора, имена пунктов меню и языковой вариант мультиязычных
колонок. Это и есть цена: человек, переключивший язык «чтобы посмотреть
одно поле», получает другой язык в сайдбаре.

Альтернатива — по своему выбору у каждого экрана — означала бы, что
таблица и открытая из неё карточка показывают одну строку на разных
языках, а колонка «Название» подписана не тем языком, каким показано
её значение.

Побочное следствие: в проекте, где языки данных — `en` и `cyr`,
сайдбар теперь подписан по-английски даже у русского интерфейса.
Это правда о данных: русской подписи у этих пунктов нет.
