# Шаблон микрофронтенда ucode

Содержимое для **шаблонного репозитория в GitLab**, который бэкенд
форкает при создании микрофронтенда
(`ucode_go_function_service/api/handlers/mcp_project.go:106`,
конфиг `GitlabProjectIdMicroFrontReact`).

Пока шаблон не переведён на это содержимое, каждый новый микрофронтенд
рождается прежнего поколения: React 18, `exposes: {"./App": ...}`, своя
авторизация. Админка такие поддерживает и будет поддерживать
(`docs/adr/0008`), но одинаковыми они от этого не станут.

Правка шаблона — задача в чужом репозитории. Здесь лежит то, что нужно
туда положить, целиком: три файла и ни одного лишнего.

Договор — в README пакета уровнем выше.
