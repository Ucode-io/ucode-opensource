# @ucode/remote-sdk

Договор микрофронтенда ucode. Мажор пакета — это номер договора:
`1.x` → `contract: 1`.

## Главное правило

**У микрофронтенда нет своей авторизации.**

Токен админки живёт только в замыкании (`shared/api/session.ts`), в
localStorage его нет. Свой axios с токеном «откуда-нибудь» брать
неоткуда — и это не ограничение, а причина, по которой всё остальное
работает: единственный живой токен приезжает вам пропсом.

Ремоуты прежнего поколения делали иначе и подбирали в хранилище чужой
токен восьмидневной давности. Разбор — в `docs/adr/0008` админки.

## Сборка

```js
// vite.config.js
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import { ucodeRemote } from "@ucode/remote-sdk/vite";

export default defineConfig({
  plugins: [react(), ucodeRemote({ name: "my_app", page: "./src/Page.jsx" })],
  build: { target: "esnext", modulePreload: false, outDir: "build" },
});
```

Пресет сам выставляет `exposes` и `shared` — менять их не нужно и
нельзя. Что в них зашито и почему, написано прямо в `src/vite.js`;
короткая версия: `requiredVersion: "^19"` обязателен, иначе вам
достанется React 18 хоста, а `react/jsx-runtime` обязан быть общим,
иначе ваш JSX не примет наш рендерер.

Сборка должна лежать по адресу `<ваш-хост>/assets/remoteEntry.js` —
именно туда ходит админка.

## Страница

```jsx
import { createApi } from "@ucode/remote-sdk";

export default function Page(props) {
  const api = createApi(props);
  const { environment, params, i18n } = props;

  // Ответ уже развёрнут: конверт бэкенда снимает админка.
  const load = () => api.v2.get("/items/orders", { params: { limit: 20 } });
  ...
}
```

Что приезжает пропсами — в `src/index.d.ts`. Коротко: `activationKey`,
`environment`, `i18n`, `params` и две оси http.

## Чего делать нельзя

- **Заводить свой корень React.** Ваша страница живёт в дереве админки,
  обычным компонентом. `react-dom/client` вам не дадут: попытка утащит
  вторую копию рендерера в вашу сборку.
- **Ждать роутер-контекст хоста.** Админка на TanStack Router,
  `react-router-dom` она не отдаёт. Нужен роутинг внутри — заведите
  свой и не рассчитывайте на адресную строку админки.
- **Держать состояние в localStorage под ключами `persist:*`.** Это
  ключи прежнего поколения, админка их стирает.

## Совместимость

Админка знает договоры до 1 включительно. Ремоут, объявивший больший
номер, не запустится — вместо белого экрана человек увидит «собрано под
более новую версию админки». Порядок выката поэтому такой: сначала
админка, потом ремоуты.
